# Voxro beta teaser (26 s)

Announcement teaser for the private beta. It shows no product interface, on purpose.

## What is real
- Logos: X Layer (`xlayer-icon.svg`), TapeOut (`tapeout-mark.svg`), ShieldSuite shield (1024 px original), OKX mark (simple-icons).
- Claims: live on X Layer mainnet (chain 196), built for TapeOut, private beta, opens 23 November 2026, voxro.shieldsuite.xyz.
- The message cards hold no text, and the chip traces are decorative.
- Narration (George), score and sound effects: ElevenLabs. The key is read at runtime and never stored here.

## Build it
`npm install`, `npm run vo`, `npm run music`, `npm run sfx`, `npm run draft`, `npm run render4k`, `npm run finish`, `npm run poster`
